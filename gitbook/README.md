# 欢迎来到 RobinCop Bot

RobinCop Bot 是一款面向投资者的自动化跟单工具。它帮助用户持续关注目标账户或公开交易信号，并依据用户预先设定的规则生成提醒或执行跟随操作，让交易计划更及时、更有纪律。

> **重要提示**：RobinCop Bot 是交易辅助工具，不提供投资建议，也不承诺收益。任何交易都可能产生亏损，请仅投入你能够承受损失的资金。

## RobinCop 能做什么？

* **自动监控**：持续追踪你选择的目标或交易信号。
* **规则化跟随**：按照金额、比例和风险限制处理交易。
* **风险控制**：通过单笔上限、总仓位限制和暂停开关控制风险。
* **状态通知**：在发现信号、执行成功或出现异常时及时提醒。
* **记录可追溯**：保留信号、操作与结果，方便复盘。

## 它适合谁？

RobinCop 适合希望减少重复操作、用明确规则管理跟单行为，并愿意独立承担交易风险的用户。它不适合寻求“稳赚”、无法承受本金波动，或不了解所交易资产风险的人。
