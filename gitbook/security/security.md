# 安全与账户保护

## 保护你的凭证

RobinCop 官方人员不应通过私信索要密码、助记词、私钥或完整 API 密钥。任何索要上述信息的人都可能在实施诈骗。

## 使用最小权限

如果通过 API 连接交易账户，只开放策略运行所必需的读取和交易权限。除非产品功能明确需要且你完全理解风险，否则不要开放提现或转账权限。

## 防范钓鱼

* 从官方渠道保存入口，不依赖搜索广告；
* 检查域名、Bot 用户名和授权页面；
* 不扫描来源不明的二维码；
* 对“保证收益”“限时充值”或主动私聊保持警惕。

## 发现异常时

1. 立即暂停所有策略；
2. 撤销 API 密钥或第三方授权；
3. 修改相关密码并启用双重验证；
4. 查看近期登录、订单和资产记录；
5. 通过官方支持渠道报告问题。
