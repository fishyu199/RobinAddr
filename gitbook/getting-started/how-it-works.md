# 工作原理

RobinCop Bot 的典型流程分为五步：

1. **监控目标**：系统读取用户选择的目标或信号源。
2. **识别变化**：发现新的买入、卖出或仓位变化。
3. **规则检查**：验证资产范围、资金上限、价格偏差和其他限制。
4. **提醒或执行**：根据策略发送通知，或向已连接的交易账户提交订单。
5. **返回结果**：记录成功、部分成交、跳过或失败，并通知用户。

## 为什么结果可能不同？

跟单并不等于复制出完全相同的成交。以下因素都可能造成差异：

* 信号产生和接收之间存在延迟；
* 市场价格快速变化；
* 资产流动性不足；
* 用户设置的金额、比例或限制不同；
* 订单可能部分成交、被拒绝或取消；
* 数据源或交易平台出现延迟与中断。

因此，即使跟随同一个目标，不同用户的成本、仓位和最终收益也可能不同。
