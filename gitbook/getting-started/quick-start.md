# 开始使用

## 1. 打开 RobinCop Bot

通过官方入口访问 RobinCop Bot：**[待补充：产品链接或 Bot 用户名]**。

请只使用官方公布的入口，不要通过陌生私信中的链接连接账户或提交敏感信息。

## 2. 创建账户或开始会话

按照界面提示完成注册、登录或 Bot 初始化。若平台要求身份验证，请确认页面域名和授权范围正确。

## 3. 连接交易账户

选择受支持的交易平台并完成授权：**[待补充：支持的平台及授权方式]**。

建议：

* 仅授予交易所必需的最小权限；
* 不启用提现权限；
* 为 RobinCop 创建独立的 API 密钥；
* 开启双重验证，并定期轮换密钥。

## 4. 添加跟随目标

搜索或输入目标账户，核对身份后添加。不要只根据短期收益决定跟随对象；应同时了解其历史回撤、持仓集中度、交易频率和风险水平。

## 5. 设置风险规则

先从较小金额开始，设置单笔上限、累计上限和允许交易的资产范围。建议首次使用“仅提醒”或模拟模式（如产品支持），确认信号符合预期后再考虑自动执行。

## 6. 启动并观察

启用策略后，检查第一笔信号的计算金额、价格和结果。定期复核持仓与授权；不再使用时，应暂停策略并撤销相关访问权限。
