# 常见问题

## RobinCop Bot 会保证收益吗？

不会。任何交易都存在亏损风险，历史表现也不能保证未来结果。

## 跟单结果为什么和目标不同？

常见原因包括信号延迟、价格变化、流动性不足、订单最低金额、用户策略限制和部分成交。

## 我可以随时停止吗？

策略应支持随时暂停。暂停通常只会阻止新操作，不一定会自动卖出已有持仓；请在产品界面核对实际状态。

## RobinCop 能提现吗？

出于安全考虑，为自动化交易创建的 API 密钥不应包含提现权限。具体授权能力以正式产品说明为准。

## 应该从多少资金开始？

没有适合所有人的金额。建议从你能够完全承受损失的小额开始，并先验证通知、规则和执行结果是否符合预期。

## 目标卖出时，我的持仓一定会全部卖出吗？

不一定。实际结果受策略比例、可用持仓、最小订单、价格限制和市场流动性影响。

## 如何判断消息来自官方？

只信任官网和已验证官方频道列出的账号。官方人员不会索要密码、助记词或私钥。官方渠道列表：**[待补充]**。
